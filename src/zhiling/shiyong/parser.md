# 🎉 使用

|   指令   |          参数           |         权限          | 需要@ | 范围 |       说明        |
| :------: | :---------------------: | :-------------------: | :---: | :--: | :---------------: |
| 开启解析 |            -            | SUPERUSER/OWNER/ADMIN |  是   | 全部 |     开启解析      |
| 关闭解析 |            -            | SUPERUSER/OWNER/ADMIN |  是   | 全部 |     关闭解析      |
|    bm    | bv号或引用一个链接/卡片 |           -           |  否   | 全部 |   下载 B 站音频   |

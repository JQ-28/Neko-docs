# 快速上手

欢迎来到 Neko 的小窝！这里是给新朋友的 5 分钟指南，跟着三步走就能和 neko 玩起来喵~

---

## 第一步 · 把 neko 请进群

neko 目前住在许多 QQ 群聊里，想让她来你的群做客，需要先通过审核。两个途径任选其一：

- 填写 [邀群问卷](/qunliao)，说明你的群和用途（问卷页内含在线申请表单）
- 直接加入 [小猫窝地下室](https://qun.qq.com/universal-share/share?ac=1&authKey=vMjh2ULH9US8HuGMccqVtTpewIbIm%2Bl0f7XCAjnYAFJlJQCjRDNLYr0OTT%2FjpXFa&busi_data=eyJncm91cENvZGUiOiIxMDYxODc4MDQyIiwidG9rZW4iOiJsOWFlbzdBK251SnlLbEdjMUtlbGNIbTNVYlp3Y1lWQlFRWUJQOGFnQ0srSkt5NXVxR1o5VlV3VkE2R1lNaitmIiwidWluIjoiNDgwMzUyNzE2In0%3D&data=-2NyJE-uEwgwJLO5jZG9chSIH_vc1dPMVAASpB3akNFqV5Bcf7XRdwLgTMCqkoAB285vr36EeOcepSFMQzvI7Q&svctype=4&tempid=h5_group_info) 主群，在里面喊一声 JQ，说明你的群和用途

审核通常在 **1-3 个工作日**内完成，通过后 JQ 会主动联系你，把 neko 拉进群。

:::info 注意
未经允许请勿擅自将 neko 拉入群聊，也不要私聊骚扰 neko 哦。
:::

## 第二步 · 发指令开始玩

neko 的大部分功能是**被动触发**的——在群里发对应指令，她就会回复。想知道她都会什么：

- 去 [指令速查](/zhiling/cheatsheet) 搜索你想用的功能，支持一键复制指令
- 不确定怎么说？点导航栏的 **问问neko**（或按 `Ctrl+Shift+K`），用大白话问她就帮你找

:::tip 新手推荐先玩这几个
`签到`（攒好感度和喵喵币）、`jrrp`（今日人品）、`/roll`（随机选择）、`今日猫娘`
:::

## 第三步 · 遇到问题怎么办

neko 偶尔会不理人或者答非所问，先别急，按顺序试试：

1. 查看 [常见问题 FAQ](/zhuyi/faq)，大多数情况都在里面
2. 去 [喵喵信箱](https://input.nekodayo.top/) 投信反馈，或者看看 [使用须知](/zhuyi/xuzhi)
3. 还不行就在 [小猫窝地下室](https://qun.qq.com/universal-share/share?ac=1&authKey=vMjh2ULH9US8HuGMccqVtTpewIbIm%2Bl0f7XCAjnYAFJlJQCjRDNLYr0OTT%2FjpXFa&busi_data=eyJncm91cENvZGUiOiIxMDYxODc4MDQyIiwidG9rZW4iOiJsOWFlbzdBK251SnlLbEdjMUtlbGNIbTNVYlp3Y1lWQlFRWUJQOGFnQ0srSkt5NXVxR1o5VlV3VkE2R1lNaitmIiwidWluIjoiNDgwMzUyNzE2In0%3D&data=-2NyJE-uEwgwJLO5jZG9chSIH_vc1dPMVAASpB3akNFqV5Bcf7XRdwLgTMCqkoAB285vr36EeOcepSFMQzvI7Q&svctype=4&tempid=h5_group_info) 主群里喊一声 JQ，或者在 [反馈页](/about/fankui) 留言

:::warning 提醒
neko 是免费纯公益运营的，遇到问题请友好反馈，辱骂和恶意刷屏会被拉黑哦。
:::

# 隐私政策

**版本生效日期：2026年09月16日**

:::tip 一句话
我们只收"跑这些功能必需"的那点数据：不卖数据、不投广告、不拿聊天记录去做别的事。
:::

这份政策说的是：Neko_dayo~ QQBot（下面叫「机器人」）、Neko 文档站、Neko 功能站各自会收集什么、拿去干什么、存在哪儿、留多久。用之前请读一遍，用起来就表示你同意。

:::info 覆盖了哪三个地方
| 部分 | 在哪 | 是什么 |
|------|------|--------|
| 机器人 | QQ 群聊 / 私聊 | 提供各类指令功能的 QQBot |
| 文档站 | `docs.nekodayo.top` | 指令文档、状态页、邀群申请、问问 neko |
| 功能站 | `tools.nekodayo.top` | 图片处理、链接解析这些在线小工具 |
:::

## ⌗ 机器人用各个功能时会记什么

这些数据都跟你的 QQ 号绑着，**只给对应的那个功能用**，不会挪去别处。

| 功能 | 记什么 | 为什么 |
|------|--------|--------|
| 签到 / 好感度 | 好感度、喵喵币、印章与里程碑进度 | 排行榜和收集册要展示 |
| 抽卡 | 各个卡池抽到了什么 | 查历史记录、做统计 |
| 绑定游戏账号 | 各平台的 token、Cookie、UID、设备参数这些凭证 | 只在你主动发绑定指令时保存，用来代你查战绩、体力、面板；解绑或联系我们就能删 |
| 词云 | 群号、消息条数、你上传的词云形状图 | 形状图按群分开存，随时能删 |
| @ 追踪 | 谁在什么时候 @ 了谁 | 群里发 `#清除艾特数据` 就能自己清 |
| 娱乐互动 | 戳戳次数、婚约关系、漂流瓶内容、人品值、随机结果 | 榜单、后续查询、互动连贯性 |
| 订阅推送 | 订阅的 B 站 / 微博账号、油价推送开关 | 好把更新推给你 |

## ⌗ 系统自动记下来的

| 记什么 | 说明 |
|--------|------|
| 运行状态 | 机器人和各个服务的在线情况、当天收发消息的**条数**（只是计数，跟内容无关） |
| 硬件读数 | CPU / GPU 温度、负载、功耗、开机时长、进程数（状态页展示用） |
| 访问日志 | 文档站访问产生的标准 Web 日志 |
| 接口调用 | 调文档站接口时的 IP 与时间，只用于限流和挡机器人，很快就失效 |
| 在线人数 | 一串随机标识与最后一次报到的时间（首页那句「现在有 N 只猫在逛」） |

## ⌗ 关于聊天消息

:::warning 这一条以前写反了，现在照实说
**机器人确实会保存聊天消息的原文**，群聊和私聊都在内。

这页以前写的是"消息原文我们不保存"，那是不对的。事实是：词云、群聊报告、谁问我了这几类统计，都得先把消息存下来才算得出来。

- **留多久**：按 30 天清理。清理程序需要定期手动执行，所以**实际可能比 30 天长**，请按"消息会被保存一段时间"来理解。
- **@ 与引用的记录**（"谁问我了"这个功能）：单独一份，只留 3 天，到期自动清；想立刻删，群里发 `#清除艾特数据`。
- **群聊报告**：[这个功能](/zhiling/AI/GroupInsight)会把群消息交给 AI 生成话题与金句摘要，每天定时自动跑一次，**生成后会一直留档**，不会自动过期。
- **词云**：只输出词频统计图，不会把完整对话摆出来。
- **拿来做什么**：只有统计。**不会拿去训练模型、不卖、不做广告、不给第三方**（下面那张第三方清单里也没有它）。
:::

## ⌗ 导航栏上的「问问 neko」

就是导航栏右边那个小图标（也可以按 `Ctrl+Shift+K` 打开），一个帮你找指令的小助手。数据这样流动：

- **聊天内容**：你问的话（不超过 50 字）和最近几句上下文会发给 **Cloudflare Workers AI** 生成回答，**不写进数据库**。能对上指令的时候，只在浏览器和文档站的指令表里找，不走 AI。
- **查资料**：有些问题会去查公开资料，这时你的关键词会发给对应站点（萌娘百科、B 站热搜、60s 热搜接口）。
- **语音输入**：录音在浏览器里就转成文字编码发到文档站接口，交给 **Workers AI 的语音识别模型**转写成文字，然后立刻丢掉。**录音和识别结果我们都不存。**

### 浏览器里存了什么

文档站会在你浏览器里存点小数据，让体验连贯一些。**都在你自己的设备上，我们看不到**，清空浏览器数据就全没了。

- **问问 neko 的聊天记录**：最近 40 条，刷新后还能接着看。
- **彩蛋进度**：你发现了哪些彩蛋。这一项会用 Cookie 在 `.nekodayo.top` 的各个站点间共享，所以你在功能站点亮过的，文档站也记得。
- **首页那两只猫的记性**：你上次来的时间、今天来过几次、连着第几天，只为让她把「第几天见啦」那句话讲对。
- **几个开关和偏好**：导览看没看过、公告读没读过、喵化语言开没开、网页主题色选的是哪个。
- **在线人数用的随机标识**：一串随机字符，跟你是谁没有关系。

### 首页那句「现在有 N 只猫在逛」

是真的在数，不是写死的数字。

- 你的浏览器生成一串随机字符存在本地，每 30 秒带着它来报一次到，页面切到后台时会暂停。
- 服务器**只记这串字符和最后一次报到的时间**，超过 90 秒没来报到的会被清掉。我们**不知道你是谁**：不关联 QQ 号、不记 IP、不记你看过哪些页面。
- 换个浏览器或者清一下浏览器数据，你就成了一只全新的猫。
- 接口按 IP 限了频率（防止有人刷数字），这个 IP 只用于限流，不会写进统计表。

## ⌗ 功能站（tools.nekodayo.top）

- **图片处理**（漫画翻译、智能抠图、以图搜源等）：你上传的图会转发给提供该能力的外部接口，结果直接回给你。**功能站自己不存你的图。**
- **链接解析**（B 站、抖音、小红书等）：你粘的链接用来去对应平台要公开的媒体信息。
- **信息查询**（健康分析、多源日报等）：你填的参数只用于这一次计算。

---

## ⌗ 数据存在哪

- 结构化的数据放在 **Cloudflare D1**，图片与截图放在 **Cloudflare R2**。
- 图片和截图通过 `drive.nekodayo.top` 读取，反馈内容通过 `input.nekodayo.top`（喵喵信箱）查看。
- 服务器在境外（Cloudflare 的全球网络），数据可能落在境外机房。
- 我们使用 Cloudflare 提供的访问控制与密钥管理，挡住没有授权的访问。

## ⌗ 会经过哪些第三方

只发"这个功能必需的那点内容"，不会额外带上你是谁：

| 服务 | 用来做什么 | 会给到什么 |
|------|-----------|-----------|
| Cloudflare（D1 / R2 / Workers AI / Turnstile） | 存数据、AI 推理、人机验证 | 见上面各节 |
| 游戏 / 社交平台的官方接口 | 代你查战绩、体力、抽卡 | 你绑定时给的凭证与查询参数 |
| 萌娘百科、热搜与日报数据源 | 回答知识类问题、生成日报 | 你的查询关键词 |
| 功能站背后的外部图片接口 | 翻译、抠图、以图搜源 | 你上传的图 |
| `count.getloli.com`（文档站访问计数器） | 统计文档站访问量 | 这个服务会记录访问请求的 IP、浏览器标识等，细节看它自己的说明 |

第三方怎么处理收到的东西，由它们自己的政策管，我们插不上手，介意的话可以先看一眼它们的说明。

## ⌗ 我们不会做的

- 不出售、不出租你的任何信息
- 不拿去做广告定向投放
- 不把聊天消息用在统计之外的任何地方（词云 / 群聊报告 / @ 记录存的是什么，上面写清楚了）
- 不把你的数据用在与功能无关的事上
- 没经过你同意，不把你的数据给第三方（上面那张表里的服务商除外）

---

## ⌗ 存多久，怎么删

- 运行状态与硬件读数只留**最近一段**（新的覆盖旧的），给状态页实时展示用。
- 聊天消息按 30 天清理（需要手动跑清理程序）；@ 与引用的记录 3 天自动清。
- 邀群申请与截图在审核完成后按需清理；想删随时找我们。
- 功能数据大多可以自己清：`#清除艾特数据` 清 @ 记录、`skland unbind` 解绑森空岛账号、词云形状图可以删；浏览器里存的那点数据，清空浏览器数据即可。
- 你随时可以：
  - 问我们手里存了你的哪些信息
  - 让我们删掉你的申请数据、截图与功能数据
  - 不想用了，撤回同意、停止使用

## ⌗ 安全上做了哪些

- 邀群申请用 **Cloudflare Turnstile** 做人机验证，挡批量提交。
- 上传的截图只收常见的图片格式，读取时会再核一遍类型。
- 状态上报与审核接口各自带独立密钥，外面伪造不了。
- 文档站与功能站的接口都按 IP 限流，防止被批量刷取。

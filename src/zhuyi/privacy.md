# 隐私政策

**版本生效日期：2026年09月14日**

:::tip 🔒 一句话承诺
我们只在「提供服务所必需」的范围内收集最少的数据，**不保存聊天记录原文、不出售数据、不投放广告**。

您的信任是我们运营这只公益猫娘的最大动力。
:::

欢迎使用 Neko_dayo~ QQBot（以下简称"本机器人"）、Neko 文档站与 Neko 功能站。我们深知个人信息的重要性，将按本政策所述收集、使用和保护您的信息。使用本产品即表示您已阅读并同意本政策。

:::info 🧭 本政策覆盖的范围
| 部分 | 入口 | 说明 |
|------|------|------|
| 本机器人 | QQ 群聊 / 私聊 | 提供各类指令功能的 QQBot |
| 文档站 | `nekodayo.top` | 指令文档、状态页、邀群申请与「问问 neko」 |
| 功能站 | `tools.nekodayo.top` | 图片处理、链接解析等在线小工具 |
:::

## ⌗ 我们收集什么

### ✓ 您主动提交的信息

| 场景 | 收集内容 | 用途 |
|------|---------|------|
| [邀群申请](/qunliao) | QQ 号、昵称、群信息、入群截图 | 人工审核您是否符合入群条件，截图存储于对象存储（R2） |
| [问题反馈](/about/fankui) | 您填写的反馈内容 | 改进服务、回复您的问题 |
| [功能站](https://tools.nekodayo.top/) | 您上传的图片、粘贴的链接、输入的参数 | 完成翻译、抠图、搜图、解析等处理 |

### ✓ 机器人功能产生的信息

在群里使用不同功能时，机器人会按该功能的需要记录少量数据。**这些数据都绑定到您的 QQ 号，且仅用于对应功能本身**，不会挪作他用。

| 功能 | 涉及数据 | 说明 |
|------|---------|------|
| 签到 / 好感度 | 好感度、喵喵币、印章与里程碑进度 | 用于排行榜与收集册展示 |
| 抽卡功能 | 原神 / 星铁 / 明日方舟 / 鸣潮等卡池的抽取结果 | 用于查询历史记录与统计 |
| 游戏账号绑定 | 各游戏平台的 token、Cookie、UID、设备参数等凭证 | 仅在您主动发送绑定指令时保存，用于代您查询战绩、体力、面板；可按对应功能的帮助指令解绑或联系我们删除 |
| 词云 | 群号、消息计数、您上传的词云形状图片 | 形状图每个群独立保存，可随时删除 |
| @ 消息追踪 | 谁在何时 @ 了谁 | 可在群内发送 `#清除艾特数据` 自主清除 |
| 娱乐互动 | 戳戳次数、婚约关系、您投递的漂流瓶内容、人品值历史、随机结果 | 用于榜单、后续查询与互动连贯性 |
| 订阅推送 | 订阅的 B 站 / 微博账号、油价推送开关 | 用于向您推送更新 |

### ✓ 系统自动产生的信息

| 数据 | 说明 |
|------|------|
| 状态上报 | 机器人运行状态、服务在线情况、当日收发消息**条数**（不含内容） |
| 硬件读数 | CPU/GPU 温度、负载、功耗、系统运行时长、进程数（用于状态页展示） |
| 访问日志 | 文档站访问产生的标准 Web 日志 |
| 接口调用记录 | 调用文档站接口时的 IP 与时间（仅用于限流与人机验证，短时间内自动失效） |

:::warning ⚠ 关于消息内容
- 私聊与群聊的**消息原文我们不保存、不查看**。状态上报里的「消息条数」只是计数，与内容无关。
- **唯一的例外是[群聊报告 / 词云 / 谁艾特我](/zhiling/AI/GroupInsight)**：这三个功能需要读取群内消息才能统计。其中 `#群聊报告` 会把群消息交给 AI 生成话题与金句摘要，报告会缓存一段时间；@ 记录会写入数据库，您可随时发送 `#清除艾特数据` 清除。词云只输出词频统计图，不会展示完整对话。
:::

## ⌗ 文档站与「问问 neko」

文档站右下角的「问问 neko」是指令速查小助手，数据流向如下：

- **对话内容**：您输入的问题（不超过 50 字）与最近几条上下文会发送给 **Cloudflare Workers AI** 用于生成回答，**不写入数据库**。命中指令时只在浏览器与文档站的指令索引内做匹配，不经过 AI。
- **知识查询**：部分问题会转去查询公开资料，此时您的关键词会发送给对应站点（萌娘百科、B 站热搜、60s 热搜接口）。
- **语音输入**：录音在浏览器内转成文本编码上传到文档站接口，交由 **Workers AI 语音识别模型**转写成文字后立即丢弃。**我们不保存音频，也不保存识别结果。**

### ✓ 浏览器本地存储与 Cookie

文档站会在您的浏览器里存一点小数据，让体验更连贯。**这些数据只存在于您的设备上，我们无法读取**，清空浏览器数据即可全部删除。

| 名称 | 类型 | 用途 | 有效期 |
|------|------|------|--------|
| `neko-chat-history` | localStorage | 保留问问 neko 最近 40 条对话，刷新后还能接着看 | 直到您清除 |
| `neko-eggs` | localStorage + Cookie | 记录您已发现的网站彩蛋进度 | Cookie 365 天 |
| `neko-visits` | localStorage | 记录连续访问天数 | 直到您清除 |
| `neko-footer-tour` | localStorage | 记住底部导览是否已看过 | 直到您清除 |
| `announcement:*` | localStorage / sessionStorage | 记住公告是否已读，避免重复弹出 | 长期 / 当次会话 |

:::tip 🍪 关于彩蛋 Cookie
彩蛋进度会在 `.nekodayo.top` 及其子域（文档站、功能站）之间共享，这样您在任意一个站点发现的彩蛋都能被记住。该 Cookie **不包含任何个人身份信息**，只是几个彩蛋编号。
:::

## ⌗ 功能站（tools.nekodayo.top）

功能站提供一批图片处理与信息查询小工具：

- **图片处理**（漫画翻译、智能抠图、以图搜源等）：您上传的图片会转发给提供该能力的外部接口完成处理，结果直接返回给您。**功能站本身不留存您的图片**。
- **链接解析**（B 站、抖音、小红书等平台）：您粘贴的链接用于向对应平台请求公开的媒体信息。
- **信息查询**（健康分析、多源日报等）：您输入的参数仅用于本次计算，不用于其他用途。

## ⌗ 数据存储在哪里

- 结构化数据存储在 **Cloudflare D1**（边缘数据库），截图与图片文件存储在 **Cloudflare R2**（对象存储）。
- 数据中心位于境外（Cloudflare 全球网络），数据可能存储在境外的数据中心。
- 我们使用 Cloudflare 提供的访问控制与密钥管理，防止未授权访问。

## ⌗ 第三方服务

为了实现上述功能，部分数据会经过第三方服务商。我们**只发送完成该功能所必需的最小内容**，不会额外附带您的身份信息：

| 服务 | 用途 | 涉及数据 |
|------|------|---------|
| Cloudflare（D1 / R2 / Workers AI / Turnstile） | 数据存储、AI 推理、人机验证 | 见上文各节 |
| 游戏 / 社交平台官方接口 | 代您查询战绩、体力、抽卡等 | 您主动绑定时提供的凭证与查询参数 |
| 萌娘百科、热搜与日报数据源 | 回答知识类问题、生成日报 | 您的查询关键词 |
| 功能站的外部图片接口 | 翻译、抠图、以图搜源 | 您上传的图片 |

第三方服务商对其收到的数据按各自的隐私政策处理，我们无法控制其行为，建议您留意对应服务的说明。

## ⌗ 我们不会做什么

- ✘ 不出售、不出租您的任何信息
- ✘ 不用于广告定向投放
- ✘ 不保存私聊与群聊的消息原文（群聊报告 / 词云 / @ 记录除外，见上文说明）
- ✘ 不将您的数据用于与功能无关的用途
- ✘ 不在未经您同意的情况下向第三方提供您的数据（上表所列服务商除外）

## ⌗ 数据保留与删除

- 状态上报与硬件数据仅保留**最近一段时间**（滚动覆盖旧数据），用于状态页实时展示。
- 邀群申请与截图在审核完成后按需清理；您可随时联系我们删除。
- 功能数据大多可以自助清除：`#清除艾特数据` 清除 @ 记录、`skland unbind` 解绑森空岛账号、词云形状可删除；浏览器本地数据清空浏览器存储即可。
- 您有权：
  - ✓ 查询我们保存了您的哪些信息
  - ✓ 要求删除您的申请数据、截图与功能数据
  - ✓ 撤回同意并停止使用

---

## ⌗ 安全保护措施

- 邀群申请接口使用 **Cloudflare Turnstile** 人机验证，拦截自动化滥用。
- 截图上传仅接受服务端白名单内的图片类型，读取时强制校验 Content-Type。
- 状态上报与审核接口使用独立令牌（`API_TOKEN`）鉴权，外部无法伪造上报。
- 文档站与功能站接口均有按 IP 的限流，防止被批量刷取。

## ⌗ 未成年人

本机器人适合全年龄段使用，我们不会主动向未成年人索取真实身份信息。若您未满 14 周岁，请在监护人陪同下使用，并由监护人阅读并同意本政策。
